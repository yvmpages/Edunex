# Edunex

Registro personal de aprendizajes. Datos locales en el navegador (`localStorage`).

## Desarrollo

```bash
npm install
npm run dev
```

## Secciones

- **Avances** — carpetas y documentos por tema
- **Conceptos** — diccionario personal
- **Notas** — apuntes en carpetas
- **Papelera** — restaurar o eliminar permanente
